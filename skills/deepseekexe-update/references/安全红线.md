# 安全红线(必须遵守)

本文件记录 DeepSeekExe 项目必须遵守的安全规则, 任何修改不得触碰红线。

## 历史教训

曾因 App 内「保存并推送」功能把会话记录(`session.jsonl.zstd`)推到**公开** GitHub 仓库,
导致 GitHub token、DeepSeek API Key、多个密码泄露。
已通过重写 git 历史、仓库转私有、轮换凭据处理, 但教训必须记住。

## 红线清单

### ❌ 禁止

1. 禁止在 App 中加回任何"上传 / 推送 / 保存到远程"功能
2. 禁止把会话记录(`sessions/`)、`.credentials.yaml` 加入任何仓库或压缩包
3. 禁止在源码 / 文档 / 脚本中硬编码任何密钥(token、API Key、密码)
4. 禁止在日志或提示中回显凭据内容

### ✅ 必须

1. 修改代码后检查: 工作区 `git status` 不含 `sessions/` 等敏感文件
2. 涉及凭据的排查一律脱敏输出(如 `:***@` 形式)
3. 新增脚本 / 文档先自查是否包含敏感信息
4. 仓库保持私有, 不分享给未授权的人

### 🟡 谨慎

- 环境变量传递凭据时, 不回显到日志
- 打包分发前检查压缩包内无意外文件
- 会话日志默认不备份; 确需备份前先确认仓库私有且做好密钥扫描
