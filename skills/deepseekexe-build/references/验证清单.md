# DeepSeekExe 打包后验证清单

每次构建后逐项验证, 全部通过才算完成:

## 1. exe 启动

- [ ] 双击 `dist\DeepSeekExe.exe`, 启动画面出现
- [ ] 10~30 秒内窗口加载出 DeepSeek 界面
- [ ] 关闭窗口后进程全部退出(任务管理器无 DeepSeekExe / node 残留)

## 2. 引擎来源(便携版)

- [ ] 便携版启动时, node 进程命令行包含
      `runtime\node.exe ... runtime\dsh\...`
      (证明未依赖系统 Node / dsh)

## 3. zip 校验

- [ ] 解压后 exe 的 SHA256 与源文件一致
- [ ] 中文文件名(`使用说明.txt`)UTF-8 flag 正确(任意语言系统解压不乱码)
- [ ] 完整解压后 `runtime\node.exe` 与引擎入口 `bin.js` 存在

## 4. 功能抽查

- [ ] 界面可正常对话/提问
- [ ] 菜单「文件 → 退出」可正常关闭
- [ ] 关闭后端口释放(无监听残留)
